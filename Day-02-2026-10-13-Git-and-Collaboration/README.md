# Day 2 — Git and Collaboration

**Date:** 13 October 2026

## Objective
Learn how Git and GitHub support version control and team collaboration.

## Tasks Performed
1. **Repositories:** Learned how repositories store project files and their history.
2. **Branches:** Practiced using branches to develop changes separately.
3. **Commits:** Learned how commits record changes with descriptive messages.
4. **Pull Requests:** Understood how pull requests propose changes for review and merging.
5. **Code Reviews:** Learned how reviews help maintain code quality.
6. **Conflict Resolution:** Understood how to identify and resolve conflicting changes.
7. **Repository Management:** Explored how project files are organized and maintained in GitHub.

## Observations
- Git tracks changes and preserves project history.
- Branches allow changes to be developed independently.
- Pull requests support review before merging changes.

## Outcome
Understood the basic Git workflow and how GitHub supports collaboration and controlled code changes.
