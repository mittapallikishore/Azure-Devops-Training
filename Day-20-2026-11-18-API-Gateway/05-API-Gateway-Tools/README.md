# Common API Gateway Tools

## 1. Kong Gateway

Kong is an API Gateway with open-source and commercial offerings.

Features:
- Plugin architecture.
- Authentication.
- Rate limiting.
- Logging.
- Traffic management.
- Kubernetes integration.

Documentation:
https://docs.konghq.com/gateway/latest/

## 2. Amazon API Gateway

A managed API service provided by AWS.

Features:
- REST APIs.
- HTTP APIs.
- WebSocket APIs.
- Lambda integration.
- Throttling.
- Monitoring through AWS services.

Documentation:
https://docs.aws.amazon.com/apigateway/

## 3. NGINX

NGINX is a web server and reverse proxy that can also perform API Gateway functions.

Features:
- Request routing.
- Reverse proxy.
- Load balancing.
- TLS termination.
- Caching.
- Header manipulation.

Documentation:
https://nginx.org/en/docs/

## 4. Azure API Management

Azure API Management (APIM) is Microsoft's managed API management platform.

Major capabilities:
- API Gateway.
- API publishing and management.
- Developer portal.
- Authentication policies.
- Rate limiting.
- Request and response transformations.
- Monitoring and analytics.

Documentation:
https://learn.microsoft.com/en-us/azure/api-management/

## 5. Apache APISIX

An open-source, cloud-native API Gateway.

Features:
- Dynamic routing.
- Plugin architecture.
- Traffic management.
- Observability.
- Kubernetes integration.

Documentation:
https://apisix.apache.org/docs/apisix/

## 6. Tool Selection Considerations

Consider:
- Cloud platform.
- Application architecture.
- Required security features.
- Traffic volume.
- Kubernetes integration.
- Operational complexity.
- Licensing and cost.
- Monitoring and support.
- Developer experience.

## Learning Outcome

Identify common API Gateway products and understand their typical capabilities and use cases.
