# Day 1 — Azure and DevOps Fundamentals

**Date:** 12 October 2026

## Objective
Understand cloud computing, Azure resources, and basic DevOps practices.

## Tasks Performed
1. **Cloud Concepts:** Learned how cloud computing provides servers, storage, and services over the internet.
2. **Azure Regions and Resources:** Understood how Azure resources are hosted in geographical regions.
3. **Resource Groups:** Learned how related Azure resources are organized and managed together.
4. **Subscriptions:** Understood how subscriptions help manage resource access, usage, and billing.
5. **Shared Responsibility:** Learned how security responsibilities are divided between Microsoft and the customer.
6. **Azure Portal and CLI:** Explored the web portal and command-line tools for managing Azure resources.
7. **Governance and Cost Awareness:** Reviewed access control, resource organization, and ways to monitor cloud costs.

## Observations
- Azure provides a centralized platform to create and manage cloud resources.
- Resource groups make related resources easier to manage.
- Access control and cost monitoring are important for safe cloud usage.

## Outcome
Established a foundation in Azure services, cloud resource management, governance, and DevOps concepts.
