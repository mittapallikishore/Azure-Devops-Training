# Azure Cost and Governance Checklist

## Before Creating Resources

- [ ] Confirm the correct Azure subscription.
- [ ] Choose an appropriate Azure region.
- [ ] Identify the resource group.
- [ ] Review estimated pricing.
- [ ] Confirm that the resources are required.

## Security and Governance

- [ ] Apply least-privilege RBAC permissions.
- [ ] Never store secrets in source code.
- [ ] Follow resource naming conventions.
- [ ] Review resource access regularly.

## Cost Monitoring

- [ ] Review resource usage and estimated costs.
- [ ] Configure budgets and alerts where supported.
- [ ] Stop or remove unused test resources.
- [ ] Check for unwanted resources after testing.

## Evidence

Record the checks you actually performed. Do not mark an item complete unless you verified it.

## Outcome

Created a reusable checklist for safer, more cost-aware Azure resource management.
