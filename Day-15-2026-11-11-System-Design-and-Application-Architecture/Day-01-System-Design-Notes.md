# Day 15 - System Design Notes
Date: 11 November 2026

## Step 1: Understanding System Design

System Design is the process of planning how different components of an application work together to create a complete, reliable, secure and scalable system.

Main components:
- Frontend
- Backend
- APIs
- Database
- Authentication
- Cloud Infrastructure
- Monitoring

Importance:
- Helps plan application architecture.
- Defines communication between components.
- Supports scalability and reliability.
- Improves security and maintainability.
- Helps identify infrastructure requirements.

## Step 2: Software Development vs System Design

### Software Development
Software Development involves writing code, implementing features, testing functionality and fixing application bugs.

Examples:
- Developing login functionality.
- Creating registration pages.
- Writing backend APIs.
- Connecting applications to databases.

### System Design
System Design involves planning the architecture, infrastructure, components and communication of an application.

Examples:
- Selecting databases.
- Designing frontend and backend communication.
- Planning cloud infrastructure.
- Designing security and scalability.

### Comparison

| Software Development | System Design |
|---|---|
| Writes application code | Plans application architecture |
| Implements features | Plans system components |
| Develops APIs | Designs API communication |
| Implements database queries | Designs database structure |
| Fixes application bugs | Prevents architectural issues |
| Focuses on functionality | Focuses on overall system quality |

### DevOps Engineer Perspective

A DevOps Engineer understands the system architecture and identifies infrastructure, cloud resources, CI/CD, deployment, security and monitoring requirements.

## Conclusion

System Design defines how an application should be structured, while Software Development implements that design through code.
