# Day 3 — Azure Resources and Identity

**Date:** 14 October 2026

## Objective
Understand Azure resource creation, identity management, access control, and secure handling of secrets.

## Tasks Performed
1. **Resource Group:** Learned how to organize related Azure resources within a resource group.
2. **Azure Resources:** Explored basic Azure resources in a sandbox environment.
3. **Microsoft Entra ID:** Learned how Azure manages identities for users and applications.
4. **Role-Based Access Control (RBAC):** Understood how permissions are assigned based on roles.
5. **Managed Identities:** Learned how Azure resources can authenticate to supported services without storing credentials in application code.
6. **Secrets Management:** Reviewed safe ways to store credentials and sensitive configuration values.

## Observations
- Resource groups help organize and manage Azure resources.
- RBAC supports least-privilege access by granting only the permissions required.
- Managed identities reduce the need to store credentials in code.
- Secrets should not be committed to GitHub or printed in pipeline logs.

## Outcome
Developed an understanding of Azure resource management, identity, access control, and secure secrets handling.
